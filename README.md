**Installation**

1. Open the Downloads section above.
2. Download the APK file.
3. Open the downloaded APK on your Android device.
4. Allow installation if Android asks for permission.
5. Launch Index Studio.

# Build from Source

# Download the Source Code ZIP, extract it and open the project in a compatible Android development environment.

# Build with Google Colab

1. Download "IndexStudio_Build.ipynb".
2. Open "Google Colab" (https://colab.research.google.com/).
3. Upload the notebook.
4. Select Runtime → Run all.
5. Follow the notebook instructions to build the APK.

# Technology

# Privacy

- Project files are stored locally in app-private storage.
- No analytics or tracking.
- No automatic project uploads to a server.

# Limitations

- Online APIs, external libraries, CDN resources and web fonts may require an internet connection.
- WebView rendering may differ slightly from desktop browsers.
- Features requiring external servers will not work fully offline.
